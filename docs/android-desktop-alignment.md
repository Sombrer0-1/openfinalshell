# 安卓版与桌面版对齐

把安卓版补成和桌面版同一套远程运维工作台：连接、终端、文件、监控、转发、命令和设置的主要操作对齐，手机和平板用各自的布局承载。优先复用已有模型、仓库和传输接口；只有字段而没有运行时行为的能力，在对应阶段补齐实现。

对照基准为截至 2026-10-14 的桌面仓库 `E:\develop\openfinalshell` 与安卓仓库 `E:\develop\openfinalshell-android` 工作区，包含当时未提交的改动，版本同为 0.30.31。桌面采用 Electron / React、活动栏、会话标签和会话内面板；安卓采用单 Activity + Compose。后续实现以各阶段列出的行为和验收为准。

## 保留的安卓能力

- 本机 shell 三档：应用 uid、Shizuku ADB、root。保留权限探测与 root 确认。Play 构建继续使用 `-PlocalShell=false`，隐藏本机 shell 添加入口，连接执行层也保持该限制。
- 命令库和 OpenAI 兼容的 AI 助手。桌面已移除 AI，安卓保留，入口调整到命令工作区，终端选区仍可带入提问。
- SAF 选文件、选目录、上传下载，以及现有打包上传和打包下载。桌面的拖拽和默认下载目录，在安卓上由 SAF 承载；系统分享接入后复用同一上传流程。
- 加密导出、局域网配对和 Keystore 凭据。本机 shell 配置、命令历史和 AI 配置保持现有的导出与同步排除规则。桌面 DPAPI 和两端的本机 `materialRef` 不作为可迁移的私钥材料。

## 平台边界

| 能力 | 安卓处理 |
| --- | --- |
| 嵌入式 RDP、系统 `.rdp`、RDP 剪贴板与音频 | 导入时识别并跳过，报告数量 |
| 多实例窗口 | 使用应用内多会话标签 |
| SSH Agent | 认证使用密码和已导入私钥 |
| WebGL 终端、独立编辑器窗口、窗口缩放 | 终端沿用 Termux 模拟器和现有原生视图；编辑器用全屏页；字号走设置 |
| 资源管理器拖文件进 SFTP | 使用 SAF 和系统分享 |
| 桌面应用内差量更新 | 沿用安卓现有 GitHub Release 检查与安装 |
| 跳板机、快捷键改键、传输队列跨进程重启恢复 | 不纳入本计划；桌面当前也未交付 |

远程编辑保持单文件 2 MiB、拒绝含 NUL 的二进制内容。桌面上限为 8 MiB、最多同时打开 10 个文件；安卓保留单编辑文档的工作方式。

## 信息架构

桌面的主区是一条会话：终端在中间，文件在下方分屏，监控在右侧，查找和历史浮在终端上。活动栏切换连接、快捷命令、端口转发和传输队列。

安卓当前把连接、终端、SFTP、监控做成同级页面，转发、同步、设置放在“更多”里。终端页的主要动作是回车、清屏、断开，连接卡片的主要动作是连接。

目标导航与布局：

| 可用空间 | 结构 |
| --- | --- |
| 手机或紧凑窗口 | 底栏：连接、会话、命令、更多。会话页以终端为主体，文件、监控从工具条打开下半屏面板，同一时间显示其中一个。转发、传输队列、同步、设置进入“更多”。 |
| ≥600 dp 的窗口 | 使用侧栏导航，左侧可切换连接树、命令、转发、传输，中间显示带标签的会话。空间足够时，文件在终端下方、监控在右侧。 |

600 dp 是导航切换阈值。三栏同时显示要求连接栏至少 200 dp、终端区至少 320 dp、监控栏至少 240 dp，另计分隔与间距；不足时先将监控改为浮层，再收起连接内容栏，保留侧栏入口。用户拖动分隔条不能突破这些最小宽度。

上下分栏时终端可视区至少 120 dp、文件区至少 160 dp。扣除工具条、系统边距和软键盘后无法满足时，文件或监控使用全屏子页，关闭后返回原会话。面板打开、收起、横竖屏切换和 IME 显示都保留终端缓冲及每个会话的滚动位置；按实际可视区域更新 PTY 尺寸。

会话工具条使用以下动作，触控目标不小于 48 dp，图标提供本地化内容描述：

| 动作 | 桌面 | 安卓现状与目标 |
| --- | --- | --- |
| 文件、监控 | 会话内面板 | 从同级页面改为会话内入口 |
| 查找 | 有 | 增加查找条 |
| 命令历史 | 终端浮层 | 从助手标签移到终端浮层 |
| 清屏、断开 | 有 | 保留；断线时提供立即重连 |
| 回车、Esc、Tab、Ctrl、方向键、斜杠 | 主要由物理键盘输入 | 保留屏幕按键行，空间紧张时收起辅助条 |
| AI | 无 | 从命令工作区进入，保留终端选区提问 |

视觉沿用 `OpenFinalShellColors`、强调色种子 `#1677FF` 和间距 token。成功、警告、错误色独立于强调色。连接标签的 8 色和界面强调色分别设置。

## 阶段与共同要求

每一阶段交付完整的界面、存储和运行时行为。现有函数是复用入口，其参数、字段保存和生命周期不足时，在该阶段一起补齐。下列阶段中的设置项随功能交付，阶段7只负责设置页面的整体分区和数据管理。

用户可见文案进入 `res/values*/`。英文使用默认 `values/`，新增可翻译 key 同时补齐 `zh-rCN`、`zh-rTW`、`ja-rJP`、`ko-rKR`、`ru-rRU`、`es-rES`、`fr-rFR`、`de-rDE`、`pt-rBR`。现有10种语言均有资源目录，每阶段通过 `:app:checkI18n`。

### 1. 连接管理

**现状。** 模型已有分组、备注、编码、终端类型、启动命令、心跳、超时、压缩、老算法、自动重连、监控开关、代理引用、标签色、位置标记和 `lastUsedAt`。`MainViewModel` 已有连接、代理和分组的保存、删除与连接复制入口。界面主要暴露名称、主机、端口、用户名、密码和私钥。

`saveProfile` 当前重建连接对象，未覆盖全部字段；`duplicateProfile` 未完整复制配置和密码。SSH 运行时仍固定终端类型，多个配置字段未应用。最近使用时间尚未在成功连接后更新。分组删除只处理直接所属连接，子组没有重新挂接。

**交付。**

- 连接行菜单：连接、编辑、复制连接、复制 `ssh` 命令、删除；删除需要确认。复制命令使用标准 `ssh -p PORT USER@HOST` 形式并正确引用参数，不包含密码；私钥或代理仍需本机配置时，给出对应提示。
- 新建和编辑共用表单，基本信息外提供分组、备注、认证、终端、连接选项、标签和位置设置。密码留空保留原值，另有清除密码动作；切换认证方式时明确处理旧凭据。
- 保存以原记录为基础更新表单字段，保留未编辑的配置和导入时保留的兼容字段。本机 shell 使用自己的表单，保留协议、权限档位和启动目录。
- 复制连接生成新连接 id，完整复制配置和分组。密码等可编辑凭据复制为独立引用；私钥、代理继续引用同一管理记录。修改或删除副本的密码不影响原连接。
- 编码、终端类型、启动命令、心跳、超时、压缩和老算法配置接入 SSH 运行时。编码覆盖终端输入与输出，保留跨数据块的字符解码状态；旧算法仅在连接显式启用时生效。自动重连沿用会话管理器；监控开关先保存，在阶段5接入采集。
- 列表支持名称、主机、用户名搜索，显示标签色和位置标记，按 `maskHosts` 打码主机。
- 分组支持嵌套、新建、重命名和连接归组。删除一个分组时，其直接所属连接移到根，其子组提升到被删组的父级，保留子组内的连接；根组的子组提升到根。分组变更在一次存储操作中完成，父组选择排除自身和后代。
- 设置提供代理（HTTP CONNECT / SOCKS5，可带认证）、私钥管理和已信任主机列表。连接表单引用代理、私钥；删除前检查引用并列出引用连接。私钥通过 SAF 导入，代理隧道复用 `ProxyTunnel`，主机信任可撤销。
- 快速连接接受 `user@host`、裸主机、`host:port`、`user@host:port` 和 `ssh -p PORT USER@HOST`。IPv6 带端口时用 `[地址]:端口`；不执行输入的 shell 文本。缺用户名时在表单中补齐，保存成功后再连接。
- 每次连接成功更新 `lastUsedAt`，失败不更新。数据库列与序列化连接数据保持一致；最近使用显示时间非空的前8条。
- 外观提供与桌面相同的8个强调色。Play 构建隐藏本机 shell 添加入口。

**验收。**

1. 编辑已导入连接的主机和代理，重启后配置保持，未编辑的编码、标签等字段不变；复制后修改副本密码，原连接仍能认证。
2. 使用非默认终端类型、启动命令和非 UTF-8 样本验证运行时效果；心跳、超时、压缩和老算法设置有相应适配层验证。
3. 删除两层分组的父组，直接连接和子组按上述规则归位；被引用的代理或私钥不能删除。
4. 快速连接成功后出现在最近使用首位，失败不改变顺序；复制出的 `ssh` 命令参数正确。Play 构建中本机 shell 入口不可见。

### 2. 会话工作区

**现状。** `SshSessionManager` 按 sessionId 管理会话，并支持重连。`MainViewModel.connect` 优先复用同连接的已有会话，选择操作主要按连接进行；文件路径、文件列表和监控显示状态仍各只有一份。断线时 `ShellClosed` 会删除终端控制器，重连事件目前主要恢复转发。

**交付。**

- 普通“连接”可选择该连接已有会话；“新建会话”和“复制会话”明确创建新的 sessionId。标签操作直接指定 sessionId，支持重命名、复制、重新连接、关闭、关闭其他、关闭右侧和全部关闭。批量关闭仍在连接的会话时一次列出受影响标签并确认。
- 终端控制器、滚动位置、文件路径、导航历史、选中项和面板展开状态按 sessionId 保存。文件请求的结果只更新发起它的会话；同一会话的旧导航结果不能覆盖新导航。传输任务和编辑文档保留其源会话归属。
- 监控显示状态和采集任务按 sessionId 管理，关闭会话时停止其采集。阶段5再接入自动开启策略和完整指标。
- 工具条接入文件、监控和现有会话动作，按信息架构实现紧凑布局与分栏。连接栏、监控栏宽度和文件区高度保存在本地设置，窗口变化时按最小尺寸约束调整。
- 网络断线时保留终端模拟器和缓冲，使输入进入不可用状态；重连成功后重新打开 shell、绑定新的输入通道和输出订阅、恢复实际 PTY 尺寸，追加一行恢复标记。恢复的是新的 shell，旧前台进程和 shell 工作目录不会因此恢复。
- 自动重连沿用现有指数退避，工具条提供立即重连。用户主动关闭标签时释放模拟器、会话任务和相关资源，取消属于该会话的传输及转发。
- 主机密钥继续按主机、端口、算法存储。首次信任展示新指纹；已有密钥变化时展示旧、新指纹并阻止连接，引导用户核实后撤销旧信任，再重新连接。

**验收。**

1. 同一连接能打开两条独立会话并准确切换；两台主机的文件路径、选中项和监控数据互不串用。延迟返回的列表不覆盖另一会话或更新的导航。
2. 充足空间下终端、文件、监控同时可见；600 dp 窗口和软键盘弹出时按规则收起面板。收起、切换标签和旋转后终端缓冲及滚动位置仍在。
3. 网络中断后自动与手动重连均重新获得可输入的 shell，旧缓冲保留，恢复标记只出现一次；关闭标签后不再重连。
4. 密钥变更不能按首次信任直接通过；同主机不同算法的信任记录可独立撤销。

### 3. 终端

**现状。** 安卓使用 Termux 模拟器和 `SshTerminalView`，支持输入、清屏、选区给 AI、字号、光标样式和回滚行数。选区结束已经复制到剪贴板。当前助手执行可记录历史，普通终端命令尚无采集链路；历史上限为200条，未合并计数。回滚设置当前限制为200–20000，尚无桌面的6套配色选择。

**交付。**

- 查找条支持上一个、下一个、区分大小写、正则，覆盖当前屏幕和回滚缓冲；高亮并滚动到结果。无效正则在查找条提示，Esc 或系统返回关闭。
- 命令历史浮层支持关键词过滤、计数、最近提交时间和清空。相同命令合并计数并更新最近时间，按最近提交时间保留1000条，每条最多32768字符；记录开关放在设置 → 终端，沿用现有加密存储及导出、同步排除规则。存储实体补齐计数和最近提交时间，并保留已有历史内容。
- 为普通终端命令增加采集：按提交后的服务器回显读取完整命令，处理退格、历史键、Tab 补全和折行。不能确认命令边界、不回显的口令输入以及 vim/less 等备用屏幕内容不记录。助手和命令编辑器通过成功提交回调记录，同一次提交只记录一次。
- 历史回填不发送提交回车。单行命令插入当前行；多行历史进入阶段6的命令编辑器查看和发送，该编辑器交付前多行记录只提供查看与复制。
- 长按菜单提供复制、粘贴、全选、清屏、查找、历史、断开。选中即复制变为可关闭设置，默认保留现有行为。
- 多行粘贴确认开启时，所有终端粘贴入口共用该规则，含 CR 或 LF 的内容在发送前确认。使用终端当前的 bracketed paste 模式；确认框说明目标会话及内容，取消不发送字节。
- 配色提供 One Dark、Dracula、Nord、Solarized Dark、GitHub Light、Solarized Light 和跟随界面，实际应用到模拟器和渲染器。设置使用本地预览。
- 补齐行高和光标闪烁。回滚目标范围为1000–100000，同时更新设置校验、界面范围和控制器；若所用 Termux 版本不能承载目标上限，先在本阶段解决适配，界面不展示会被静默截断的值。回滚容量变化对新建会话生效，设置中说明。
- 屏幕按键行提供回车、Esc、Tab、Ctrl、方向键和斜杠；沿用高度不足时的收起逻辑。输出中的 `http(s)` 链接可交给系统浏览器。

**验收。**

1. 真会话中执行含补全、退格和折行的命令，历史记录完整；重复执行更新计数。口令输入和备用屏幕正文不进入历史。
2. 点击单行历史后，终端仅收到插入文本，远端命令未执行；点击多行历史不直接向终端发送换行。
3. 多行粘贴取消后远端无输入；确认后按当前终端模式发送。查找能定位回滚中的内容，配色、行高、闪烁和新会话回滚容量生效。

### 4. 文件与远程编辑

**现状。** 已有文件列举、建目录、重命名、删除、SAF 上传下载、打包传输、暂停续传重试取消、隐藏文件过滤和远程文本编辑。`MinaChannels.permissions` 可改权限。`SftpEntry` 只有名称、路径、类型、大小、权限；MINA 适配层直接提供字符串文件名。

`RemoteTextEditor` 已进行大小限制、二进制拒绝、严格编码往返校验、内容指纹冲突检测和原子替换能力检查。保存要求目标已经存在，因此新建文件需要独立的创建语义。终端目录跟随、文件名解码错误标记、文件身份核对和完整保存确认仍需实现。

**交付。**

- 工具条：后退、前进、上级、刷新、隐藏文件、上传、下载、新建文件、新建文件夹。路径可编辑并回车跳转，导航失败保持原目录；写操作使用已成功加载的目录。支持多选以执行批量下载和删除。
- 行菜单：打开、编辑、复制路径、下载、打包下载、重命名、删除、权限。打包下载和快速删除只对目录提供。文件默认点按动作可设为下载或编辑。
- 列举增加所有者标识和修改时间，缺失值显示不可用；支持名称、大小、修改时间、所有者升降序，目录始终优先，同值按名称和路径稳定排序。SSH 与本机文件适配层同时处理新增字段。
- 权限对话框提供八进制输入和读/写/执行九宫格，调用现有 `permissions`；保留未修改的特殊权限位。
- 新建文件先在内存中编辑，首次保存时以排他创建语义写入新路径，不生成本地明文临时文件。目标已存在时保持草稿，允许改名或改为打开已有文件，不默认覆盖。保存后转为普通编辑文档并建立基线。
- 快速删除只接受绝对目录路径，拒绝含 `.`、`..`、NUL、CR、LF 的路径，非空路径段至少两级；混选文件和目录时不可用。预览和执行共用路径校验及 shell 引用逻辑，正确处理空格、单引号和字面通配字符，命令使用 `rm -rf --`。展示退出结果及未删除路径；普通删除仍使用 SFTP。
- 目录跟随采用与桌面相同的有限推导：从已提交命令识别可静态确定的 `cd`，支持绝对路径、相对路径、带引号或转义的空格及 `~`。初始目录和 home 通过当前会话文件通道解析；手动导航更新跟随基准。`cd -`、变量展开及其他无法确定的形式保持原列表。推导目标列举失败时保持原列表并提示。跟随仅代表推导目标，不声称已获知 shell 的真实工作目录。
- 传输冲突支持询问、覆盖、跳过、重命名；“应用到其余项”仅作用于同一次用户发起的传输批次。重命名生成未占用目标名，上传和 SAF 下载使用相同策略含义，处理文件与目录类型冲突。
- 传输队列独立一页，显示源会话、进度、速度、剩余时间及暂停、继续、取消、重试、清除已完成；未知大小或速率时不显示虚假的剩余时间。进行中的数量显示在导航上。SAF 提供器支持偏移访问时保留续传；不支持时沿用已有能力提示。
- 在 SFTP 名称解码处保留错误状态，严格 UTF-8 解码失败的条目显示不可操作标记；不得用字符串是否含 `�` 判断错误。若 MINA 在创建条目前直接抛出解码错误，报告该目录列举失败；要提供逐条标记，须在适配层取得原始名称或错误结果。两条路径都不能使用替换后的名称执行操作。

**编辑保存契约。**

- 文档绑定源 sessionId、路径、解析后的实际目标、编码、BOM、行尾及内容基线；保存始终使用源会话。保留当前严格编解码和行尾处理，编码不可用、不能往返、目标编码无法表示字符或存在 NUL 时拒绝保存。
- 编码切换重新读取远端字节，不把当前草稿当作源字节转换；有未保存修改时先确认丢弃，取消或读取失败保留原文档和草稿。关闭或切换编辑文档时同样处理未保存修改。
- 保存前重新解析实际目标；路径仍存在而解析结果与打开时不同，则拒绝并要求重新打开。路径消失按下述文件删除冲突处理。通过 SFTP 的 realpath/元数据能力补齐目标核对，继续使用内容基线检查第三方修改；不把内容相同当作路径指向未变的证据。
- 远端内容变化或文件被删除时，提供重新读取、仍然覆盖或取消。覆盖确认只针对当次看到的远端状态，再次变化需要重新确认。取消保留草稿。
- 新内容为0字节且远端非空，或远端至少4 KiB且新内容小于其四分之一时，显示缩短确认，列出前后字节数。新建空文件不触发此确认。
- 已有文件优先同目录临时文件加原子替换。服务器不支持时，单独确认非原子保存后才使用退化路径；保持原内容可恢复，报告失败及恢复结果。该确认不同时放行内容冲突或缩短检查。
- 原子替换保留当前权限位；属主、ACL 等元数据不承诺原样保留，编辑器提供相应保存说明。成功保存后更新基线、权限和草稿状态；临时文件按现有清理路径释放。

**验收。**

1. 通过 SAF 上传目录，对其中文件重命名、改权限、下载；可定位到不同排序结果，导航失败不改变写入目标。
2. 新文件首次保存成功，再次保存走编辑流程；同名目标出现时不会被静默覆盖。编辑期间切换会话不改变保存目标。
3. `/`、`/etc`、`/data/../etc` 被快速删除拒绝；包含空格和单引号的测试目录仅删除所选目标，失败路径能显示。
4. 静态可推导的 `cd` 触发跟随，无法推导或列举失败时保持原列表；解码失败名称不会触发文件操作。
5. 支持偏移访问的 SAF 样本暂停后续传不从零开始；重命名冲突和批次内应用策略在上传、下载中生效。
6. 编码重读取消保留草稿；非法编码、目标改变、内容冲突、清空、大幅缩短和缺少原子替换分别得到对应结果。拒绝或取消时远端原文件不变，成功保存后再次保存使用新基线。

### 5. 监控与转发

**现状。** `MonitorSnapshot` 已包含运行时间、每核 CPU、负载、交换分区、全部网卡、磁盘占用和读写、Top 进程、连接计数、TCP 状态与双延迟。当前界面主要显示总 CPU、内存、交换分区、第一块网卡和最多4个挂载点。三类 SSH 转发已能启停，自动启动和重连恢复已有入口；计数字段不代表已经有真实流量采集。

**交付。**

- 在阶段2的会话状态隔离基础上展示全部已有指标，Top 进程可折叠。磁盘占用超过75%用警告色，超过90%用错误色；沿用 `UsageMeter` 和文字速率。
- 按连接的 `monitorEnabled` 在会话就绪后启动采集，按现有刷新间隔运行；监控面板收起不自动改变采集开关。会话关闭时停止，重连后重建采集并重置该会话的差分基准。
- 非 Linux 远端或采集失败给出状态与重试，本机 shell 按 `MonitorAvailability` 展示可用指标。失败或不可用指标不绘制成0，其他会话、终端和文件继续可用。
- 端口流量显示连接数和收发速率，支持刷新；计数器不可用时明确标记。
- 转发列表显示运行、停止和错误。连接数、字节数只有接入真实计数源时才展示。转发属于规则，一条规则同一时间只绑定一条 SSH 会话；已有运行绑定优先保留，新启动使用该连接当前选中的就绪会话，否则使用最早就绪会话。同连接新建标签不重复启动规则。
- 自动启动沿用已有入口；绑定会话重连后恢复，其他标签的就绪事件不抢占绑定。主动停止后，在该绑定会话的生命周期内保持停止，包括重连；主动启动可解除该状态。规则删除或关闭绑定标签后停止，本机 shell 不提供 SSH 转发。

**验收。** 两台 Linux 会话分别开启采集，切换时指标不串用；缺失能力与采集失败状态可辨认。自动启动规则绑定的会话重连后恢复，同连接复制会话不重复监听或抢占端口，主动停止与关闭标签的结果正确。

### 6. 命令

**现状。** 命令库已有分组、保存、删除、插入和执行，位于终端助手对话框。当前插入、执行入口只接受单行命令。桌面另有多行命令编辑器、当前/全部会话目标、自动回车和占位符替换。

**交付。**

- 命令成为独立导航页，提供命令库、临时编辑器和 AI 提问；AI 配置仍可从设置进入。当前目标显示会话标签，全部目标显示本次目标列表。
- 目标为具有可写 shell 的就绪会话，包括本机 shell；继续遵守本机 root 确认。重连中、已关闭及未打开终端的会话不参加发送。点击发送时确定目标集合，每个目标写入前再次检查状态。
- 正文将 CRLF、CR 归一为 LF，删除末尾空行，保留中间空行。占位符按每个目标的连接配置替换 `{{host}}`、`{{user}}`、`{{port}}`，开关关闭时保留原文；同一归一化正文用于发送与保存快捷命令。
- 自动回车开关只控制正文末尾的提交。单行关闭时只插入；多行关闭时仅在目标终端启用 bracketed paste 模式后发送整段，否则保留正文并提示该目标无法仅插入多行。开启时发送正文并追加提交，说明内部换行可能提交前面的命令；适用终端多行粘贴确认设置。
- 当前单行助手入口保留单行约束，多行发送使用明确的编辑器路径。按终端模式组装粘贴与提交字节，不通过关闭校验来扩展旧入口。
- 快捷命令可发送至当前或全部目标，使用相同目标、替换和发送规则。仅在所有目标写入成功后清空编辑器；部分成功时保留正文，列出成功和失败目标，重试仅选择失败目标，避免重复执行。
- 命令历史表示已提交内容，不表示远端执行成功。程序化发送在成功写入且包含提交时，按目标替换后的完整正文记录，复用阶段3的长度限制、去重计数和单次记录规则。仅插入不记录；不支持仅插入的目标不发送也不记录。
- 本页显示最近20条，点击回填编辑器，不直接执行。单行与多行历史共享一份存储。

**验收。**

1. 两条连接配置不同的会话分别收到对应占位符替换结果；验证收到的是配置中的地址、用户名和端口。
2. 单行关闭自动回车后远端未执行；多行在 bracketed paste 模式下只插入，否则该目标无输入；开启后按预期提交且无 CRLF 引入的额外空行。
3. 批量发送有一个目标失败时正文保留，成功目标不因重试再次收到命令；历史只记录成功提交内容，点击历史不发送字节。

### 7. 设置、导入与导出

**现状。** 设置已有10种语言及相应资源，当前页面较长。导出界面使用“包含机密 + 整文件加密”的固定组合，底层支持两种格式与机密选择。`PortableExport.importInto` 当前按 id 检查冲突，副本模式尚未完整重映射关联字段，也没有类别选择。

**交付。**

- 设置分为常规、外观、终端、传输与监控、代理与私钥、安全与数据、局域网同步、关于。将前六阶段的设置归入对应区段。外接键盘的查找、历史、复制粘贴和关闭标签快捷键接入后提供只读说明。
- 导出提供两个独立选项：包含已存机密、整文件加密。机密范围包括连接密码、代理密码和私钥口令；包含机密时始终需要口令保护，整文件加密沿用现有口令要求。关闭整文件加密时，配置为可读格式，机密仍单独加密。命令历史、AI 配置及本机 shell 配置继续排除。
- 私钥仅导出可迁移元数据及可选口令，不导出 Keystore 材料或桌面 DPAPI 密文。导入后标记材料缺失，允许通过 SAF 重新选择私钥并绑定原记录；不会使用源设备路径当作本机可用材料。
- 导入提供类别选择与预览：连接、分组、代理、私钥元数据、转发、命令库、主机信任。所选项需要的父分组、代理、私钥元数据、目标连接和命令分组在预览中列出并一并选择；取消必需依赖时取消对应依赖项，避免写入悬空引用。
- 冲突按同类别稳定 id 判断，名称用于展示；同名但不同 id 的记录可并存。同 id 提供跳过、覆盖、另存为副本。预览列明动作及缺失机密、私钥材料。
- 导入先确定所有记录的目标 id，再重写分组 parentId、连接 groupId/proxyId/privateKeyId、转发 profileId 和命令 groupId。跳过项映射到已有本机记录，副本项映射到新记录；同一批次内的关联始终使用最终映射。
- 所需机密使用新本机凭据引用并重写相应字段，只导入最终选中记录实际使用的机密。跳过项不改其机密，覆盖项缺少机密时清除不可用引用并标记待补录。导入验证完关联后再写入。覆盖私钥元数据时，材料指纹一致才继续绑定已有材料；指纹不一致则阻止覆盖该私钥及依赖项，允许改为副本后重新选取材料，不删除本机有效材料。
- 已有主机信任不被文件覆盖：同键同指纹跳过，同键不同指纹报告冲突并保留本机信任；新信任记录须在导入预览中明确选择。主机信任不通过追加随机 id 制造副本。
- FinalShell 数据目录通过 SAF 选取，扫描连接和分组。导入名称、主机、端口、用户名、编码、备注和分组，用户名缺失沿用桌面默认值 `root`；密码、私钥、代理、转发不导入。预览报告不支持、无效记录与未知编码，未知编码回落 UTF-8 并提示。分组重建引用，重复连接按主机、端口、用户名提供跳过或另存。
- 导出与局域网同步继续使用现有线协议；本计划新增的会话布局、显示状态等本机设置不进入共享数据。

**验收。**

1. 对包含机密和整文件加密的四种组合验证文件可读范围及口令行为；带密码连接可在另一台安卓或桌面导入并认证，历史、AI 配置和本机 shell 配置不在文件中。
2. 私钥连接导入后显示待重新选取材料，重新绑定后可连接；覆盖导入不会删除已有有效材料。
3. 包含两层分组、代理、私钥元数据、连接、转发和命令分组的样本，分别按跳过、覆盖、副本及类别选择导入，所有引用均指向预览中的目标记录；副本机密不修改原记录，取消类别不留下无用机密。
4. 同名不同 id 可并存，已有主机信任冲突不被覆盖。FinalShell 样本分组正确，连接没有密码引用，未知编码和不支持记录有数量或逐项说明。

桌面主窗口是标题区里的会话标签、48px 活动栏、可折叠侧栏、中间会话、可选右侧监控和 24px 状态栏。设置是盖在工作台上的分区对话框，而不是换掉会话。

安卓在宽度 ≥600dp（平板横屏，以及够宽的手机横屏）使用同一套信息架构：

- 活动栏宽 48dp，图标为连接、命令、转发、传输；底部是主题和设置。再点当前项收起侧栏，会话留在中间。

- 状态栏显示连接点、会话名、`user@host`、传输速率、编码和版本。
- 设置和局域网同步以对话框打开，底下的终端模拟器不卸载。
- 没有会话时，中间是欢迎页：快速连接和最近使用的主机。
- 连接行是单行列表（名称、地址、状态点、菜单），整行点按即连接或回到已有会话。设置按桌面的分区一次只显示一区；宽窗口左侧是分区列表。
- 界面使用固定的中性表面和强调色，不用随设备变化的动态取色。

宽度 &lt;600dp 时用底栏：连接、会话、命令、更多。会话页不再叠一层大标题。从连接列表成功选中新会话后进入会话页。文件和监控仍按原有最小高度规则收成下半屏或全屏。

## 会话保活

离开应用、旋转、从最近任务划掉界面，都不应当关闭 SSH。会话模型挂在 `Application` 的 `ViewModelStore` 上，不随 Activity 销毁。只要还有未关闭的会话、传输、转发，或一次连接尝试尚未结束，就运行前台服务：

- 类型是 `specialUse`（维持 SSH，而不是 6 小时上限的 `dataSync`）。
- 常驻通知，点按回到应用。
- 部分唤醒锁只在有会话时持有，屏幕保持关闭，心跳线程仍能发 `SSH_MSG_IGNORE`。
- Wi-Fi 下加低延迟 Wi-Fi 锁，避免电台休眠。
- 用户关闭全部会话后停止服务并释放锁。
- 强制停止或进程被杀死后套接字不复存在。系统若以空 Intent 拉起服务，只提示重新打开，不再假装会话还在。

厂商省电仍可能杀掉前台服务。设置 → 常规里可以请求忽略电池优化。若离开应用后会话仍断，需要在系统设置里为 OpenFinalShell 打开不受限制的电池、自启动和后台活动。小米、华为、OPPO、vivo 和三星的「睡眠」或「深度优化」不看应用自己的唤醒锁。Android 13 及以上还需要允许通知，否则前台服务通知不可见，部分系统会据此回收进程。
