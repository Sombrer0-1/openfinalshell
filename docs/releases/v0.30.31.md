## 0.30.31

OpenFinalShell 提供远程运维工作台：SSH 终端、SFTP 文件管理、嵌入式 RDP、远程编辑、服务器监控、端口转发、快捷命令和传输队列。

- Windows 可在设置中开启多个独立窗口。连接配置和凭据在窗口之间共享，会话与传输队列保持隔离。
- 支持加密导出、导入和局域网同步。凭据由当前系统账户的安全存储保护。
- 界面提供深浅主题、强调色、缩放和 10 种语言。

### English

OpenFinalShell is a remote operations workspace with SSH terminals, SFTP file management, embedded RDP, remote editing, server monitoring, port forwarding, command snippets, and a transfer queue.

- On Windows, independent windows can share connection settings and credentials while keeping sessions and transfer queues isolated.
- Encrypted export, import, and LAN sync are included. Credentials stay in the current system account's secure storage.
- The interface provides light and dark themes, accent colors, zoom, and 10 languages.
