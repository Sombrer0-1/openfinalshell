## 0.30.31 更新内容

本次更新统一桌面工作台的视觉样式，并改善高缩放、键盘操作和辅助显示偏好下的使用体验。

- **统一深浅主题与八种强调色。** 标题栏、侧栏、欢迎页、设置、监控和独立编辑器使用一致的表面、边界、文字与状态色；强调色的显示颜色根据背景调整对比度，已有配色设置与连接标签颜色保持兼容。
- **统一常用控件。** 改善终端、SFTP、传输和监控工具栏的按钮、面板标题、空状态及加载反馈；图标按钮提供可访问名称和原生键盘操作。
- **修复高缩放布局。** 小窗口及 150% UI 缩放下，设置弹窗与连接编辑抽屉按可用视口限制尺寸，内容可滚动，关闭与保存操作保持可达。
- **适配辅助显示偏好。** 减少动效、减少透明度、高对比度及强制颜色模式下采用对应回退样式；背景采用静态效果。

保留紧凑的多会话布局、Ant Design 复杂表单与虚拟表格、xterm 终端、CodeMirror 编辑器及现有 IPC/设置体系。主窗口与独立编辑器继续同步主题；新增回归覆盖切换主题、标签和文件面板后终端连接、编辑草稿与撤销历史的保留。

### 验证范围

- 本轮 UI 改造的本地全量测试：1734 项通过、37 项按原配置跳过；类型检查、10 种语言键检查、生产构建和原有体积预算检查通过。
- Windows 本地目录包完整业务冒烟通过：SSH/SFTP、监控、命令历史、工具栏提示避让、批量传输，以及独立编辑器的中文输入法、保存、撤销和远端冲突确认。
- UI 专项验证通过：64 张截图、89 项断言，覆盖深浅主题、八种强调色、十种语言的代表页面、多种视口和 90%–150% UI 缩放；未记录到渲染异常。
- 版本更新后重新通过类型、国际化、9 项更新说明测试、构建与体积检查；Windows 多实例冒烟的 13 个检查全部通过，包括跨窗口 SSH/SFTP 隔离、关闭一个窗口后另一窗口继续传输，以及重启后凭据仍可解密。
- 此次验证不代表真实 RDP 主机互操作或 macOS/Linux 原生桌面实机验收完成。发布工作流继续执行各平台构建与原有门禁。

### English

Refresh the desktop workspace with consistent light/dark themes, accessible accent colors, shared toolbar controls and improved empty/loading states. Fix settings and connection drawers overflowing small windows at 150% UI zoom, and respect reduced motion, reduced transparency and high contrast preferences.

The existing session layout, terminal/editor engines and settings remain compatible. Local Windows regression checks cover SSH/SFTP, transfers, editor input/save/undo and session continuity through UI changes. Live RDP interoperability and native macOS/Linux acceptance still require their respective environments.
