## 0.30.32

- 服务器监控在有 `nvidia-smi` 时显示每块 NVIDIA GPU 的占用、显存、温度和功耗。
- 点击 GPU 卡片打开独立页面，按每张卡列出正在占用它的进程、用户和显存。同一进程占用多张卡时，在每张卡下各有一行。

### English

- The server monitor shows utilization, memory, temperature, and power for each NVIDIA GPU when `nvidia-smi` is available.
- Clicking the GPU card opens a page that lists the processes on each GPU, with the user and VRAM. A process using more than one GPU appears once under each GPU.
